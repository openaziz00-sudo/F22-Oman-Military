# صقور عُمان — لعبة قتال جوي ثلاثية الأبعاد

## التشغيل
- ارفع المجلد `oman_air_combat` إلى استضافة صفحات ثابتة مثل GitHub Pages أو Netlify.
- افتح `index.html` عبر خادم HTTPS أو خادم محلي؛ لا تفتح الملف مباشرة لأن تحميل نموذج GLB وملفات JavaScript يحتاجان إلى خادم.
- يتطلب اتصال إنترنت لتحميل Three.js من jsDelivr.

## التحكم
- الهاتف: اسحب الشاشة لتوجيه الطائرة، واضغط مطولاً على زر إطلاق النار.
- مستشعر الحركة: اضغط «تفعيل تحكم حركة الهاتف» واسمح بالوصول للحساس عند الطلب.
- الكمبيوتر: WASD أو الأسهم للتوجيه، وSpace لإطلاق النار.

## محتويات المشروع
- `index.html`: اللعبة ومحرك العرض ومنطق اللعب.
- `assets/f22_oman.glb`: نموذج الطائرة المرفوع المستخدم داخل اللعبة.

ملاحظة: تحكم الحركة يعتمد على دعم المتصفح لحساس DeviceOrientation وعلى HTTPS وإذن المستخدم. يوجد تحكم بالسحب ولوحة المفاتيح كبديل.
